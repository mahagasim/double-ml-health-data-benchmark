# Figures

This lightweight GitHub snapshot commits the three figures embedded in the main README:

- `bias_core_methods.svg`
- `rmse_all_methods_log.svg`
- `true_overlap_extremes.svg`

They are vector graphics for clean browser rendering. The complete figure suite is reproducible from the frozen raw Monte Carlo outputs with `scripts/make_figures.py`; raw replication-level CSVs are omitted from this portfolio snapshot for size but their hashes and generation seeds are recorded in `results/run_manifest.json`.
